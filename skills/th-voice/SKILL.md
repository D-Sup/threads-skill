# th-voice

설치 직후 딱 하나만 더 하는 일이다. 이걸 안 하면 어디서 본 것 같은 남의 말투로 나온다.
예전에 쓴 글을 보여주고 말투 파일을 만들어 두면, 11개 스킬이 전부 그 말투로 쓴다.

## 사용자가 주는 것 (원본 가이드와 같은 한 번의 요청)

```
templates/voice.md 양식으로 내 말투 파일 만들어줘.
내가 쓴 글이랑 반응 좋았던 글 몇 개 붙여넣을게.
계정 소개: [무엇을 / 누구에게 / 어떤 분위기로]
완성되면 ~/.claude/threads/voice.md 로 저장해줘.
```

팁: 존댓말인지 반말인지, 자주 쓰는 말버릇, 절대 안 쓰는 표현까지 적어주면 훨씬 비슷해진다.

## 순서

1. `~/.claude/threads/voice.md` 가 있으면 읽고, 무엇을 바꿀지는 사용자가 준 내용대로만 바꾼다.
2. 글이 없이 요청만 왔으면 위 요청 틀을 보여주고 **글과 계정 소개를 붙여넣어 달라고 한 번만** 말한다.
   질문을 하나씩 이어 묻지 않는다.
3. 받은 글에서 말투를 뽑는다: 어미(존댓말/반말/음슴체), 문장 길이, 자주 쓰는 말, 이모지 습관.
4. 이 폴더의 `voice-template.md` 양식(저장소의 `templates/voice.md`와 같다)대로 채운다.
   - 말투 샘플 칸에는 받은 글을 **원문 그대로** 붙인다.
   - 사용자가 말하지 않은 칸(내 입장, 써도 되는 근거, 금지 주제 등)은 **빈칸으로 둔다.**
     짐작해서 채우거나 '제안'을 적지 않는다.
5. `~/.claude/threads/voice.md` 에 저장한다(폴더가 없으면 만든다).
6. 저장한 내용을 보여주고, 비어 있는 칸을 짚어준다.

## 규칙

- **지어내지 않는다.** 숫자·경험·입장은 사용자가 준 것만 쓴다. '써도 되는 근거'가 비어 있으면
  초안에 `{{내 숫자}}` 자리가 남는다고 알려준다.
- 남의 계정 말투를 따라 해 달라고 하면, 내 글이 없다는 점을 먼저 말한다. 남의 글은 샘플 칸에 넣지 않는다.

## 끝나면

```
VOICE 저장 · ~/.claude/threads/voice.md
분야:     프론트엔드 개발 (2~3년차 개발자에게)
말투:     반말 + 음슴체 섞음, 짧게 끊음, 이모지 안 씀
비어 있음: 써도 되는 근거, 내 입장 (채우면 초안이 덜 비어 나온다)

다음: /th-post 로 첫 글, 또는 /th-plan 으로 이번 주 계획
```

## 원본과 다른 점

원본에는 이 스킬이 없다. 원본은 `templates/voice.md` 양식만 두고, 가이드에서 "내 글 붙여넣고 이 양식으로 만들어줘"라고
한 번 요청하게 한다. 여기서는 그 한 번의 요청을 스킬 이름으로도 부를 수 있게 한 것뿐이고, 하는 일은 같다.
양식은 원본과 같은 칸·같은 순서이고, 영상 전용 칸(얼굴 노출, 내레이션, 말하는 속도)만 쓰레드 칸(존댓말 여부, 문장 길이)으로 바꿨다.
