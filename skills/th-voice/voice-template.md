# voice.md

이 파일을 `~/.claude/threads/voice.md` 로 복사해서 채운다. 모든 스킬이 이 파일을 먼저 읽는다.
직접 채우기 귀찮으면 `/th-voice` 를 실행하고 내가 쓴 글 3~5개를 붙여넣으면 된다.
그쪽이 직접 답을 짐작해서 쓰는 것보다 정확하다.

이 파일이 비어 있으면 모든 초안이 '어디서 본 것 같은 남의 말투'로 나온다.

---

## 나는 누구인가

- **이름 / 핸들:**
- **분야:** (예: 프론트엔드 개발 / 동네 카페 / 육아 / 홈트 / 1인 쇼핑몰 / 디자인)
- **한 문장으로 하는 일:**
- **누구에게 말하나:** (넓게 말고 구체적으로. "개발자" 말고 "첫 이직 준비하는 2~3년차 백엔드")
- **이 계정으로 얻고 싶은 것:** (팔로워 / 문의 / 판매 / 채용 제안 / 그냥 기록)

## 나는 어떻게 말하나

- **내가 쓴 글 중 나다운 것 3개:** (그대로 붙여넣기)
- **말투:** (존댓말 / 반말 / 음슴체 / 섞어서)
- **분위기:** (담백 / 유쾌 / 날카로움 / 다정 / 건조)
- **자주 쓰는 말버릇:**
- **절대 안 쓰는 표현:** (예: "꿀팁", "~하는 법 총정리", "여러분")
- **이모지:** (안 씀 / 가끔 하나 / 자유롭게)
- **문장 길이:** (짧게 끊음 / 길게 이어 씀)

## 내 입장

내 분야 사람들 일부는 동의하지 않을 내 생각 3~5개. 좋은 글은 여기서 나온다.

1.
2.
3.

## 올리는 방식

- **하루 몇 개:** (기본 1~2개)
- **주로 쓰는 형식:** (단독 글 / 연결글 / 섞어서)
- **주제 태그 후보:** (글 하나에 하나만 붙는다. 자주 쓸 것 3~5개)
- **링크 걸 곳:** (블로그, 깃허브, 가게 주소 등)

## 쓰면 안 되는 것

- **다루지 않는 주제:**
- **밝히면 안 되는 이름·숫자·회사:**
- **할 수 없는 주장:** (의료·금융·법률 같은 규제 분야, 회사 정책, 계약상 비밀)

## 써도 되는 근거

내 이름을 걸어도 되는 실제 숫자, 결과, 이야기. 스킬은 절대 숫자를 지어내지 않는다.
여기가 비어 있으면 초안에 `{{내 숫자}}` 자리가 남는다.
