# th-viral

이 묶음에서 유일하게 '보러 가는' 스킬이다. 나머지는 쓴다. 한 달에 한 번이면 충분하다.
공식은 한 철 간다.

이 폴더의 도구:

```bash
python3 rank.py captured.tsv --out ~/.claude/threads/swipe.md
```

## 이 스킬의 핵심 한 가지

**조회수 자체는 증거가 아니다.** 팔로워 50만 계정의 조회수 10만은 평범한 날이다.
팔로워 3천 계정의 조회수 10만은 뭔가를 찾은 거고, 그 뭔가는 따라 할 수 있다.

그래서 **배수**(이 글 조회수 ÷ 그 계정 최근 글 조회수 중앙값)로 순위를 낸다.
3배 넘으면 신호, 1.5배 아래는 그 계정의 평범한 날이라 배울 게 없다.

쓰레드는 남의 글 조회수도 공개다(글을 누르면 보인다). 조회수가 안 보이는 글은
좋아요로 대신 계산하고, 덜 정확하다고 표시한다.

계정은 **내 크기의 10배 안쪽**에서 고른다. 팔로워 200만 계정에서 먹히는 공식은
200만이라서 먹히는 경우가 많다.

## 1단계: 계정 고르기

6~12개를 받거나 제안하고 승인받는다:

- **4개 직접 경쟁:** 같은 분야, 조금 앞선 계정
- **4개 옆 분야:** 분야는 다르고 독자는 같은 계정. 형식은 여기서 먼저 빌려 온다.
- **2~4개 큰 계정:** 형식만 본다. 속도·말투는 따라 하지 않는다.

사용자가 '저장한 글'을 열어보게 한다. 이미 취향으로 걸러진 가장 좋은 자료다.

## 2단계: 보러 가기

이 세션에 있는 도구(브라우저, 사용자 크롬에 붙는 도구 등)를 쓴다.

**어기면 안 되는 규칙:**

- **사용자 대신 로그인하지 않고 비밀번호를 묻지 않는다.** 로그인이 필요하면
  사용자가 이미 로그인한 브라우저를 사용자와 함께 쓰거나, 붙여넣어 달라고 한다.
- **긁어 가기가 아니라 읽기다.** 계정 10개, 글 10여 개씩, 사람 속도로. 대량 자동 수집은
  Meta 약관 위반이고 계정이 막힌다. 크롤러를 만들지 않고, 수집 서비스를 쓰지 않고,
  백그라운드로 반복하지 않는다.
- **공식을 따라 하지, 글을 베끼지 않는다.** 첫 줄의 모양, 구조, 길이. 문장과 경험은
  내 것이어야 한다. 스와이프 파일의 모든 줄에 출처 계정을 붙인다.
- 공식 API의 키워드 검색은 남의 공개 글까지 보려면 Meta 앱 심사가 필요하다.
  심사를 받은 사용자만 쓴다.

**글마다 적을 것** (탭으로 구분한 파일):

| 열 | 설명 |
| --- | --- |
| account | 핸들 |
| followers | 프로필 숫자 |
| median | 최근 글 12개쯤 조회수 중 가운데 값 (눈대중으로 정렬해서 가운데) |
| views | 이 글 조회수 ('4.1만'처럼 적어도 된다) |
| likes, replies, reposts | 보이는 대로 |
| hook | 첫 줄, 맞춤법 틀린 것까지 원문 그대로 |

median이 가장 중요하다. 이게 없으면 다시 팔로워 순위가 된다.

## 3단계: 순위

```bash
python3 rank.py captured.tsv --out ~/.claude/threads/swipe.md
```

배수, 훅 공식 이름(`th-post/hooks.json`), 훅 점수, 위 1/3과 아래 1/3의 차이를 낸다.

## 4단계: 무슨 뜻인지, 조심해서

세 가지만 말한다:

1. **위 1/3에 몰린 공식.** 계정 6개에 걸쳐 같은 공식이 네 번 나오면 발견이다.
   두 번이면 아니다.
2. **위와 아래의 구조 차이.** 첫 줄 길이, 숫자가 있는지, 질문으로 끝나는지,
   연결글인지, 천 조회당 답글.
3. **분류 안 된 글.** 공식에 안 맞는 첫 줄은 소음이거나 `hooks.json` 에 아직 없는
   공식이다. 직접 읽는다. 가장 값진 칸이다. 새 공식이면 `hooks.json` 에 추가하자고 제안한다.

표본 크기와 신뢰도를 말로 밝힌다. 계정 6개 글 40개면 주장할 만하다. 12개면 아니다.

## 5단계: 내 버전으로

위 공식 셋마다 **사용자의 버전**을 쓴다. 사용자의 이야기, 사용자의 숫자로.
"이 글처럼 써보세요"가 아니라 내일 바로 쓸 수 있는 첫 줄을 준다. 그리고 `/th-post` 로 넘긴다.

swipe.md의 '내 버전' 칸에 적어 둔다. `/th-post` 와 `/th-plan` 이 이 파일을 읽는다.

아무것도 올리지 않고, 팔로우·좋아요·답글도 하지 않는다. 읽기만 한다.
