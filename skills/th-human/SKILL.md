# th-human

이 폴더의 도구 두 개는 실제로 돌아간다. 눈대중으로 하지 않는다.

```bash
python3 humanize.py draft.txt -o clean.txt --report   # 고치고, 바뀐 것 보여주기
python3 detect.py draft.txt                            # 다섯 기준 채점
python3 detect.py draft.txt clean.txt                  # 전후 비교
```

둘 다 `slop.json` 을 읽는다. 한국어 상투어·과장어·업무체 표현과 바꿀 말, 보이지 않는
문자, 문장부호, 그리고 표시만 할 문장 구조 목록이다. 고쳐 쓰라고 만든 파일이다.
사용자가 원래 자주 쓰는 말이 지워진다면 그 줄을 지운다.

## 쓰레드에서 이게 더 중요한 이유

쓰레드 글은 짧다. 500자 안에서 "결론적으로" 하나, 이모지 체크 목록 하나가 차지하는
비중은 긴 블로그 글보다 훨씬 크다. 탐지기에 걸리는 게 문제가 아니라, 사람들이
'또 AI 글이네' 하고 넘기는 게 문제다.

## 자동으로 고치는 것

1. **보이지 않는 문자.** 폭 없는 공백·연결자, BOM, 이름 없는 서식 문자는 지우고,
   특수 공백은 보통 공백으로.
2. **문장부호.** 긴 줄표(—)를 쉼표로, 둥근 따옴표를 곧은 따옴표로, …를 ...로.
   줄표를 지우면서 생기는 이중 문장부호도 정리한다.
3. **상투어.** '함께 알아볼까요?', '도움이 되셨기를 바랍니다'는 지우고,
   '혁신적인→새로운', '인사이트→배운 점'처럼 쉬운 말로 바꾼다.
   **바꾼 말의 받침에 맞게 조사(을/를, 이/가, 은/는, 과/와, 으로/로)도 고친다.**
   URL 안은 건드리지 않는다.

## 자동으로 안 고치는 것

문장 구조는 **표시만** 한다. 모양을 바꾸려면 판단이 필요해서다:

- '단순히 X가 아니라 Y', 'X뿐만 아니라 Y도', 'X가 아닙니다. Y입니다'
- '결과는?' 같은 한 줄 수사 질문
- '첫째, 둘째, 셋째' 나열
- 이모지 글머리 목록(✅ 🔥 📌)
- 느낌표 연타, '저장 필수'·'팔로우하고' 같은 반사적 부탁
- 태그 벽 (쓰레드는 주제 태그 하나만 붙는다)
- '~니다.'로 네 번 넘게 연달아 끝나는 문장

이 목록은 직접 고친다. 뜻은 그대로 두고 문장을 바꾼 뒤 `detect.py` 를 다시 돌린다.
REVIEW를 PASS로 올리는 건 이 부분이고, 스크립트는 못 한다.

## 다섯 기준

`detect.py` 는 다섯 신호를 0~100점(높을수록 사람 같음)으로 매긴다:

| 기준 | 재는 것 | 기계처럼 보이는 모습 |
| --- | --- | --- |
| 문장 리듬 | 문장 길이 변화 | 모든 문장 길이가 비슷함 |
| 구체성 | 100어절당 숫자·이름·인용 | 추상명사뿐, 숫자 없음 |
| 상투어 | 100어절당 목록 표현 | 뻔한 말 |
| 흔적 문자 | 보이지 않는 문자, 줄표, 둥근 따옴표 | 타자로는 잘 안 나오는 문자 |
| 말투 | 끝맺음이 섞이는지, 사람(나/너)이 있는지, AI식 구조 | '~니다'만 반복, 사람이 없음 |

평균 60% + **가장 낮은 기준** 40%로 합친다. 한 가지만 나빠도 티가 나기 때문이다.
PASS는 70점 이상이고 55점 아래인 기준이 없어야 한다.

## 정직하게 말할 것

이건 공개 탐지기들이 보는 신호를 본뜬 다섯 가지 휴리스틱이다. 전부 사용자 컴퓨터에서
돌고 아무것도 업로드하지 않는다. GPTZero나 카피킬러 같은 서비스가 **아니고**, 그 결과를
약속할 수 없다. 같은 걸 재기 때문에 여기서 고치면 그쪽 점수도 움직이는 경향이 있다는 것,
그게 할 수 있는 말의 전부다. "탐지 안 됩니다"라고 말하지 않는다.

## 순서

1. `humanize.py draft.txt -o clean.txt --report`
2. 표시된 구조를 직접 고친다.
3. `detect.py draft.txt clean.txt` 로 전후를 보여준다.
4. PASS가 아니면 가장 약한 기준부터 고치고 다시. 두 번은 보통이다. 다섯 번째라면
   초안 자체가 공식으로 쓰인 것이니, 더 돌리지 말고 다시 쓴다.
5. 고친 글과 점수를 함께 보여준다. 점수만 보여주지 않는다.
