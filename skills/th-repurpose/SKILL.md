# th-repurpose

좋은 긴 자료 하나에는 글이 네다섯 개 들어 있다. 대부분 하나만 꺼내고 나머지를 버린다.

## 입력

대본, 글, 뉴스레터, 원고, 통화 요약, 라이브. 링크를 주고 이 세션에 자막 도구가 있으면 쓴다.
없으면 붙여넣어 달라고 한다. 아무것도 꺼내기 전에 전부 읽는다.

자료가 사용자 본인 영상이면 캡처나 짧은 클립도 달라고 한다. 사용자 실제 화면이 붙은 글이
같은 말을 다시 쓴 글보다 낫다.

## 요약하지 말고 꺼낸다

영상 요약은 글이 아니다. 요약은 아무도 원하지 않는다. 자료를 훑으며 혼자 서는 것들을 꺼낸다:

| 꺼낼 것 | 무엇 |
| --- | --- |
| **주장** | 논쟁을 시작할 모든 문장 |
| **숫자** | 모든 수치, 비용, 기간, 비율 |
| **이야기** | 사람과 장면과 대가가 있는 모든 순간 |
| **원리** | "실제로 돌아가는 방식은..." 모든 것 |
| **실수** | 뭔가 잘못됐다고 인정한 모든 것 |
| **문장** | 그대로 인용할 만한 모든 문장 |

쓰기 전에 찾은 것을 개수와 함께 보여준다. 네 개가 안 나오면 얇은 자료고, 거기서 짜낸 글 네 개도 얇다. 그렇게 말한다.

## 그다음 꺼낸 것마다 형식을 고른다

전부 같은 형식이 아니다.

- **주장, 실수, 이야기는 단독 글로.** 목소리가 필요하다.
- **원리, 번호 목록은 연결글로.** 다시 읽어야 한다.
- **인용할 만한 문장은 답글이나 다른 글의 한 줄로.** 따로 글 하나가 되기엔 짧다.

## 그다음 한 주를 짠다

꺼낸 것 하나가 글 하나가 되고, 글마다 완전히 혼자 선다. 읽는 사람은 원본을 안 봤고 앞으로도 안 본다.
"지난 영상에서 말했듯이"라고 쓰지 않는다. 글이 그 자체다.

글마다 `th-post/hooks.json` 의 훅 공식을 붙이고, 서로 다르게 한다. 한 자료에서 나온 글 다섯 개가 같은 첫 줄 모양이면
찍어내는 계정으로 읽히고, 실제로 그렇다.

자료가 사용자 본인 영상이면 **실제 화면을 쓴다.** 그 말을 한 장면의 캡처가 다시 쓴 문장보다 매번 낫다.

한 주의 순서: 가장 센 주장을 먼저, 이야기는 주 중간에, 원리는 마지막에. 앞 글을 좋아한 사람이 그걸 기다리고 있을 때.

## 보여줄 것

```
자료: "왜 상담 전화를 없앴나" (42분 팟캐스트, 8,900단어)

찾은 것  주장 5, 숫자 9, 이야기 3, 원리 4, 실수 2, 인용할 문장 7

한 주
화  단독   #2  하지 마세요    상담 전화 그만하세요
                              14:20 장면 캡처, 끝에 웃는 부분
수  연결4  원리              전화를 대신한 질문 4개짜리 신청서
금  단독   #21 장면 한가운데   "…그리고 그 사람은 아흐레 뒤에 환불을 요청했다"
일  단독   #5  시간 압축       링크 하나 지웠더니 매주 여섯 시간이 돌아왔다

"화요일 거 써줘"라고 하면 쓸게요.
```

그다음 요청이 오면 하나씩 쓴다. 각각 `/th-post` 와 `/th-human` 으로. 다 쓴 글 네 개를 한꺼번에 쏟아내지 않는다.
전부 똑같이 들리고, 사용자는 하나도 안 올린다.

## 원본과 다른 점

| 원본 | 여기 | 이유 |
| --- | --- | --- |
| 릴스 / 카드뉴스 / 스토리 | 단독 글 / 연결글 / 답글 한 줄 | 쓰레드 형식 |
| 실제 영상 클립 쓰기 | 실제 화면 캡처 쓰기 | 글 플랫폼 |
