# threads-skill · 쓰레드 운영 클로드 스킬

**쓰레드(Threads) 운영을 클로드에게 맡기는 스킬 11개.** 무료(MIT), 가입·API 키·연결 없이 바로 쓴다.

명령어 한 줄이면 첫 줄 후보에 점수가 붙어 나오고, 500자에 맞춘 글, 연결글,
출처를 확인한 정보글, 답글 초안, 주간 계획을 받는다. 분야는 정해져 있지 않다.
개발이든 카페든 육아든, 처음에 적은 내 분야와 말투를 따라간다.

**올리는 건 내가 한다.** 이 스킬은 쓰레드에 로그인하지도, 대신 올리지도 않는다.
글을 써줄 뿐이다. 자동 답글·자동 팔로우는 계정이 막히는 지름길이라 일부러 뺐다.

## 왜 만들었나

인스타그램용으로는 [instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill)
(스타 6천 개 넘음) 같은 유명한 묶음이 있는데, 쓰레드용으로는 그만한 게 없었다.
그리고 그 묶음의 핵심 도구(훅 점수기, AI 티 검사기)는 **영어 전용**이라 한국어를 넣으면
제대로 채점하지 못한다. 영어로 85점인 훅을 한국어로 옮기면 38점이 나왔다.

그래서 그 구조를 빌려 와 쓰레드에 맞게 다시 짜고, 도구는 한국어 기준으로 새로 만들었다.

| | 원본 (인스타) | threads-skill |
| --- | --- | --- |
| 플랫폼 | 릴스·캡션·카드뉴스·스토리 | 500자 글·연결글·답글 |
| 훅 공식 | 영어 26개 (영상 대본용) | **같은 26개, 같은 번호**를 한국어 글 첫 줄로. 영상 전용 2개만 글에 맞게 |
| 훅 점수기 | 영어 단어 기준 | **한국어 어절·어미·숫자 표현** + 영어 |
| AI 티 지우기 | 영어 상투어 | **한국어 상투어 + 조사 자동 맞춤**(인사이트를 → 배운 점을) |
| 글자 검사 | 캡션 125자 잘림 | **500자 한도, 주제 태그 1개, 연결글 번호** |
| 성과 분석 | 스크린샷 붙여넣기 | 붙여넣기 + **쓰레드 공식 API(읽기 전용)** |
| 새로 넣은 것 | | **출처 확인 정보글**(`/th-source`), **말투 설정**(`/th-voice`) |

## 3분 설치

**방법 1 · 문장 하나 붙여넣기 (추천)** — 클로드 코드에 그대로 붙여넣는다:

```
https://github.com/D-Sup/threads-skill 이 스킬 설치하고 /th-post 가 되는지 확인해줘
```

**방법 2 · 플러그인 명령어**

```
/plugin install threads-skill --marketplace D-Sup/threads-skill
```

(예전 버전 클로드 코드라면 `/plugin marketplace add D-Sup/threads-skill` 후 `/plugin install threads-skill`)

플러그인으로 깔면 명령어가 `/threads-skill:th-post` 처럼 앞에 이름이 붙는다.
그냥 `/th-post` 로 쓰고 싶으면 방법 3.

**방법 3 · 직접 복사**

```bash
git clone https://github.com/D-Sup/threads-skill.git
cp -r threads-skill/skills/th-* ~/.claude/skills/
```

파이썬 3.8 이상이면 되고 따로 설치할 것은 없다.
클로드 코드가 없으면 `SKILL.md` 하나를 대화 맨 위에 붙여넣어도 그 모드로 돈다(도구 실행은 빠진다).

### 설치 직후 딱 하나: 내 말투 알려주기

```
templates/voice.md 양식으로 내 말투 파일 만들어줘.
내가 쓴 글이랑 반응 좋았던 글 몇 개 붙여넣을게.
계정 소개: [무엇을 / 누구에게 / 어떤 분위기로]
완성되면 ~/.claude/threads/voice.md 로 저장해줘.
```

이걸 안 하면 어디서 본 것 같은 남의 말투로 나온다. 존댓말인지 반말인지,
자주 쓰는 말버릇, 절대 안 쓰는 표현까지 적어주면 훨씬 비슷해진다.
적지 않은 칸은 짐작으로 채우지 않고 빈칸으로 둔다.
결과는 `~/.claude/threads/voice.md` 에 저장되고, 11개 스킬이 전부 이 파일을 읽는다.

## 스킬 11개

| 명령어 | 이럴 때 |
| --- | --- |
| `/th-voice` | 처음 설정. 내 분야·말투·써도 되는 숫자를 정리한다 |
| `/th-post` | 아이디어 하나를 글로. 첫 줄 후보 3개에 점수, 단독 글 또는 연결글, 500자 검사 |
| `/th-source` | 링크·문서·뉴스·릴리스 노트로 정보글. **원문과 대조한 사실만**, 출처 붙이기 |
| `/th-viral` | 내 분야에서 지금 먹히는 글 찾기. '그 계정 평소보다 몇 배'로 순위 |
| `/th-plan` | 이번 주 계획. 기본 주 4~5개(voice.md에 적으면 그 개수), 형식·시간·공식 번호, 답글 달 계정 10개 |
| `/th-reply` | 내 글에 달린 답글 정리. 기회·내용·질문·응원·소음으로 나누고 급한 것부터 |
| `/th-comment` | 남의 글에 달 답글. 아홉 가지 종류 중 글에 맞는 것으로, "공감합니다" 금지 |
| `/th-repurpose` | 영상·블로그·회고 하나를 일주일치 글로 쪼개기 |
| `/th-profile` | 프로필 100점 만점 채점, 깎인 곳부터 고친 문장 |
| `/th-audit` | 내 지난 글 분석. 배수·천 조회당 답글로 무엇을 더 하고 덜 할지 |
| `/th-human` | AI 티 지우기. 상투어·줄표·보이지 않는 문자 제거, 다섯 기준 채점 |

예시 (대괄호 안만 내 상황으로):

```
/th-post [레거시 빌드가 12분에서 2분으로 줄었는데 원인이 소스맵 설정이었음]
/th-source [링크] 이거 [사장님] 입장에서 핵심만
/th-viral 내 분야는 [홈카페]야. 비슷한 계정 중에 평소보다 크게 터진 글 찾아줘
/th-plan 다음 주 계획. 이번 주에 있었던 일은 [신메뉴 출시, 리뷰 하나 받음]
/th-reply 답글 붙여넣을게. 급한 것부터 답글 초안 써줘
```

## 실제로 돌아가는 도구

의존성 없음, 네트워크 없음(fetch_insights.py만 예외), 업로드 없음. 내 컴퓨터에서 내 글로만 돈다.

### 훅 점수기 · `th-post/hookscore.py`

```
$ python3 hookscore.py hooks.txt

HOOK RANKING (훅 순위)
==============================================================================
->  84.6 STRONG  아무도 안 알려주는데, 첫 글 30개는 반응 없는 게 정상이에요
    81.4 STRONG  서버비 40만 원을 날린 이유는 캐시 설정 한 줄이었다.
    76.6 STRONG  원두 냉동 보관 그만하세요. 2주 안에 쓸 양만 사는 게 낫습니다.
    44.0 WEAK    요즘 AI가 정말 많이 발전하고 있는 것 같습니다
        약한 기준: 긴장감 (20)
     0.0 WEAK    안녕하세요 여러분 오늘은 콘텐츠 전략에 대해 이야기해볼게요
        감점: 인사로 시작. 피드에 인사받으러 온 사람은 없다.
        감점: 준비 문장('오늘은 ~에 대해'). 지우고 핵심부터 쓴다.
```

길이·구체성(숫자, 이름)·긴장감(손해, 반전)·핵심 위치·말 거는 대상, 다섯 가지를 본다.
조회수 예측기는 아니다. 인사, 서론, 아무 내용 없는 첫 줄을 걸러내는 데 쓴다.

### 500자·연결글 검사 · `th-post/chain.py`

```
$ python3 chain.py draft.txt

연결글 3개 · 총 640자
========================================================================
  1/3   74/500  OK    배포 버튼 누르고 퇴근했는데, 10분 뒤 전화가 왔다.
  2/3  499/500  WARN  ...
              - 한도까지 1자. 수정하다 넘치기 쉽다
  3/3   67/500  FAIL  다음부터는 배포 전에 이 세 가지를 확인한다. #배포…
              - 주제 태그 2개. 쓰레드는 글 하나에 하나만 붙는다
  상태: FIX  (FAIL부터 고친다)
```

`---` 줄로 연결글을 나눈다(코드 블록 안의 `---` 는 빼고). 날짜("11/9", "3/5")를 연결글 번호로
잘못 읽지 않도록 연결글 전체를 보고 판단하고, `---` 없이 번호만 붙인 연결글이나 1번 글의 링크도 알려준다. 이모지를 몇 자로 세는지는 공식 문서로 확인하지 못해서,
`--strict` 를 주면 이모지를 크게 세는 보수적인 계산도 보여준다.

### AI 티 지우기 · `th-human/humanize.py`, `detect.py`

```
$ python3 humanize.py draft.txt --report
  고침   [상투어] '급변하는 시대에' -> '요즘'
  고침   [상투어] '인사이트' -> '배운 점'        (조사도 '를'→'을'로 맞춤)
  고침   [상투어] '도움이 되셨기를 바랍니다' -> 삭제
  직접 고칠 문장 구조:
  - '단순히 X가 아니라 Y': "단순히 도구가 아니라"
  - 이모지 글머리 목록(✅ 🔥 📌)

$ python3 detect.py before.txt after.txt
  변화: 7.7 -> 39.8 (+32.2)
```

문장 리듬, 구체성, 상투어, 흔적 문자, 말투(끝맺음이 '~니다'만인지, 사람이 있는지)를 채점한다.
GPTZero 같은 탐지 서비스가 아니고 그 결과를 약속하지 않는다. 같은 신호를 볼 뿐이다.

### 벤치마킹 순위 · `th-viral/rank.py`

남의 글을 사람 속도로 읽으며 표로 적으면, 계정 평소 조회수 대비 배수로 순위를 매기고
첫 줄이 어떤 공식인지 이름을 붙인다. 쓰레드는 남의 글 조회수도 공개라서 이 방법이 그대로 먹힌다.

### 내 글 분석 · `th-audit/audit.py`, `fetch_insights.py`

`fetch_insights.py` 는 쓰레드 공식 API로 **내 글과 성과만 읽는다**(올리지 않는다).
Meta 개발자 앱과 `threads_basic`, `threads_manage_insights` 권한 토큰이 필요하다.
토큰이 없으면 숫자를 붙여넣거나 표로 적어도 된다.

```bash
THREADS_TOKEN=... python3 fetch_insights.py --limit 50
python3 audit.py ~/.claude/threads/posts.json
```

## 원본과 어떻게 맞췄나

원본 SKILL.md를 한 줄씩 옮기고, 쓰레드에 없는 기능만 바꿨다. 바꾼 곳은 각 SKILL.md 맨 아래
**'원본과 다른 점'** 표에 이유와 함께 적어 두었다.

| 원본 (13개) | 여기 (11개) | |
| --- | --- | --- |
| ig-reel + ig-caption | th-post | 쓰레드는 글과 캡션이 같다 |
| ig-viral, ig-plan, ig-reply, ig-comment, ig-profile, ig-repurpose, ig-audit, ig-human | th-* 같은 이름 | 순서·규칙·출력 모양 그대로 |
| ig-story, ig-carousel, ig-dm | 없음 | 쓰레드에 스토리·카드뉴스가 없고, DM은 넣지 않았다 |
| `templates/voice.md` | th-voice + 같은 양식 | 원본 가이드의 "내 글로 voice.md 만들어줘" 요청을 스킬로 부를 수 있게 |
| 없음 | th-source | **원본에 없다.** 소식·문서를 출처와 대조해 글로 쓰는 기능. 필요 없으면 지워도 나머지는 그대로 돈다 |

## 계정 지키는 규칙

- **써주는 건 클로드, 올리는 건 나.** 어떤 스킬도 게시·답글·팔로우·좋아요를 하지 않는다.
- **긁어 가지 않는다.** `/th-viral` 은 사람 속도로 몇 개 계정만 읽는다. 대량 자동 수집은
  Meta 약관 위반이고 계정이 막힌다.
- **지어내지 않는다.** 숫자·경험·고객 이야기는 사용자가 준 것만 쓴다. 없으면 `{{내 숫자}}` 로 비워 둔다.
- **같은 답글을 여러 계정에 붙이지 않는다.** 초안은 읽어보고 조금씩 고쳐서 단다.

만들어지는 파일은 전부 `~/.claude/threads/` 에 있다: `voice.md`, `swipe.md`, `plan.md`, `log.md`, `posts.json`.
